## 🚀 Key Features

- 🌓 **Dynamic Theme Engine**: Seamless Light & Dark mode support with persistent state saving and custom CSS variable transitions.
- 🌐 **Multilingual Intro Loader**: Smooth animated greetings in 7 languages (English, Hindi, French, Spanish, Italian, Japanese, Korean) with GSAP spring physics.
- 🎨 **Apple-Inspired Design Language**: Glassmorphism, refined typography, subtle gradient accents, and curated cyan color palette.
- 🖱️ **Interactive Custom Cursor & Particle Canvas**: Ambient background particle network reacting to cursor physics and user interactions.
- 💼 **Deep-Dive Project Case Studies**: Interactive modals featuring problem statements, architectural diagrams, metric highlights, key takeaways, and live GitHub/Demo links.
- 📜 **Verified Credentials & Certifications**: Studio-grade credential display with copyable Credential IDs and full-screen preview modals.
- 🧭 **Storytelling Journey & Experience**: Structured milestone timeline showcasing growth from curiosity to building autonomous AI agents and cloud applications.
- ⚡ **Zero-Dependency Core**: Built with Vanilla HTML5, CSS3, and JavaScript — highly optimized, lightweight, and fast loading.

## ⚡ Quick Start & Local Setup

To run this portfolio locally on your machine:

### 1. Clone the Repository
```bash
git clone https://github.com/riddhi-z1465/portfolio.git
cd portfolio
```

### 2. Run Locally
You can open `index.html` directly in any modern browser, or serve it using a local dev server:

**Using Python:**
```bash
python3 -m http.server 8000
```

**Using VS Code Live Server:**
- Right-click `index.html` and select **"Open with Live Server"**.

**Using Node.js (npx serve):**
```bash
npx serve .
```

Visit `http://localhost:8000` in your browser.
